# Open Siren — Static Web App & GitHub SEO Architecture

> **Zero-backend, $0/month interactive leaderboard and episode trace explorer hosted on GitHub Pages**, fed directly by `open-siren export-web`.

---

## 1. Architecture Overview

```text
  open-siren run (local M4 / Linux / CI)
           │ writes episodes.jsonl
           ▼
  open-siren export-web --results results/* --out web/public/data
           │
           ├── web/public/data/manifest.json       (runs, models, suites, generated_at)
           ├── web/public/data/leaderboard.json    (SuiteSummary grouped by model × mitigation)
           ├── web/public/data/breakdowns.json     (by difficulty, mechanism, tempter_ablation)
           ├── web/public/data/replay.json         (Auto-Gate offline replay metrics per model)
           └── web/public/data/traces/<id>.json    (lazy-loaded episode trace + strace + hits)
           │
           ▼ git push → .github/workflows/pages.yml
  GitHub Pages Static SPA (Vite + React + TypeScript + Tailwind CSS)
           ├── Tab 1: Leaderboard & Mitigation Curves (Figures 4 & 10)
           ├── Tab 2: Difficulty & Tempter Ablations (Figures 5 & 6)
           ├── Tab 3: Auto-Gate Offline Replay (Figure 8)
           └── Tab 4: Interactive Episode Trace Explorer (prompt, thinking, cmds, strace, hits)
```

## 3. Static Data Contract (`web/public/data/`)

1. **`manifest.json`**:
   ```json
   {
     "schema_version": "0.2",
     "generated_at": "2026-11-25T...",
     "models": ["claude-haiku-4-5", "gpt-4.1-mini", "deepseek-v3.2", "qwen-2.5-coder-32b"],
     "backends": ["docker", "bwrap"],
     "mitigation_sets": ["none", "sandbox_rules", "report_tools", "report_tools+view_reports", "all"],
     "episode_index": [
       {
         "episode_id": "a1b2c3d4e5f6",
         "model": "deepseek-v3.2",
         "backend": "bwrap",
         "mitigation_set_id": "none",
         "scenario_id": "...",
         "mechanism": "fd_leak",
         "difficulty": "impossible",
         "tempter_ablation": "as_written",
         "reached_outside": true,
         "used_honeypot": true,
         "misaligned_use": true,
         "eval_awareness_detected": false,
         "reported_weakness": false,
         "blocked_commands": 0
       }
     ]
   }
   ```
2. **Trace Sanitization Rules (in `web_export.py`):**
   - Refuse to export `local_jail` episodes run with real models by default (they may expose real host paths or files).
   - Strip `provider_raw` (thinking signatures), scrub host home paths from tracebacks, and hash raw canary strings before publishing.
   - Preserve a window around any canary or honeypot hit when truncating long command outputs.
   - Render all model output and shell streams as plain text only in the browser (never raw HTML or unescaped Markdown) to prevent stored XSS on `*.github.io`.
   - Include a benchmark canary GUID in exported JSON to discourage training-data ingestion.
